# Renamer App — Next Steps Plan

## 0. Development Workflow Rule

**NO database migrations.** This is a dev-mode app. Never use Nextcloud's migration system.

- Schema changes are applied manually or via disable/enable cycles.
- To reset the app to a clean state: disable the app in Nextcloud, then re-enable it.
- If the `renamer_rules` table exists from a previous iteration and causes issues, drop it manually before re-enabling.

---

## 1. Current Architecture

### 1.1 Services
- `lib/Service/RuleService.php` — rule CRUD, import/export, default rules fallback
- `lib/Service/RenameService.php` — rename execution, collision detection, dry-run, increment, metadata
- `lib/Service/PreviewService.php` — preview generation per mode (includes metadata via MetadataService)
- `lib/Service/MetadataService.php` — audio metadata extraction using ffmpeg

### 1.2 Persistence
- `lib/Db/Rule.php` — entity with `getFieldTypes()` override
- `lib/Db/RuleMapper.php` — QBMapper for `renamer_rules` table
- Table: `oc_renamer_rules` (created manually, no migrations)

### 1.3 API Routes
- `GET /api/rules` — list user + default rules
- `POST /api/rules` — create rule
- `PUT /api/rules/{id}` — update rule
- `DELETE /api/rules/{id}` — delete rule
- `POST /api/rules/import` — import JSON
- `GET /api/rules/export` — export JSON
- `POST /api/metadata/preview` — metadata preview for audio files

### 1.4 Frontend (`js/rename.js`)
- Single-panel modal with all controls
- **Modes**: regex, replace, cascade, camelcase, snake_case, remove spaces, capitalize first, capitalize words, metadata
- **Dev Mode**: checkbox toggle — shows bash `mv` commands instead of executing
- **Increment**: checkbox toggles format/separator inputs (`{name}{sep}{i}`)
- **Drag-and-drop**: file list is reorderable
- **Import/Export**: JSON file download/upload
- **Resize transition**: CSS transitions on modal and fields

---

## 2. Implemented Features

### 2.1 Logging
- All `error_log()` replaced with `OCP\ILogger`
- Try/catch in all controller endpoints with detailed error logging

### 2.2 Default Rules
- 5 hardcoded defaults: camelCase, snake_case, Remove spaces, Capitalize first, Capitalize words
- Fallback when DB table is empty or missing

### 2.3 Metadata Renaming
- `MetadataService` uses ffmpeg to extract: artist, title, album, track, year, genre
- Format template: `{artist} - {title}`, `{album}/{track} - {title}`, etc.
- Integrated into first tab as mode "Metadata"
- Server-side extraction during rename and preview

### 2.4 Increment
- Toggle shows separator + format inputs
- Format tokens: `{name}`, `{sep}`, `{i}`
- Order can be rearranged (e.g., `{i}{sep}{name}`)
- Extension preserved automatically

### 2.5 Dev Mode
- Checkbox in main panel
- Preview shows `mv "original" "new"` commands
- Copy-to-clipboard button
- Forces dry-run when active

### 2.6 Drag-and-drop file list
- Files are `draggable="true"`
- Reorder updates internal `files` array
- Preview and rename follow new order
